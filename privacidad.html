Política de privacidad

Última actualización: 15 de octubre de 2026.

Quién usa la aplicación

Radar de Ofertas es una herramienta personal con un único usuario: el dueño de la cuenta de Gmail que la autoriza. No tiene usuarios externos.

Qué datos de Google usa

  • Lee los correos de alertas de empleo que el usuario etiqueta para ese fin.
  • Aplica etiquetas y crea filtros en la cuenta del usuario para organizar esas alertas.
  • Envía correos únicamente a la propia dirección del usuario. Cualquier envío a terceros requiere la confirmación explícita del usuario en cada caso.

Dónde se guardan

Los datos se procesan y almacenan solo en el computador del usuario. No hay servidores propios ni bases de datos en la nube.

Con quién se comparten

El texto de las ofertas de empleo se envía a un servicio de modelo de lenguaje (Anthropic, Claude) para evaluarlas, y las direcciones web de las ofertas se consultan en VirusTotal para revisar su seguridad. No se venden ni se ceden datos a nadie más, y no se usan para publicidad.

Uso de datos de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El usuario puede retirar el permiso en cualquier momento desde myaccount.google.com/permissions.
